# Kebijakan Privasi — M2S Klinik Kampus
Versi M01 · 7 November 2026 (prototipe tugas kuliah; hanya data dummy; belum ada server)

## 1. Data yang Kami Simpan
Akun (email, peran), profil (nama, NIM/NIP, fakultas/unit, alergi, golongan darah), booking, rekam medis, resep, serta surat rujukan dan surat sakit. Aplikasi tidak mengumpulkan lokasi, kontak, kamera, atau ID perangkat.

## 2. Di Mana Data Disimpan
Pada versi ini hanya data contoh di perangkatmu. Setelah terhubung ke server, data disimpan di layanan Firebase (Google) dan kamu perlu login. PIN aplikasi hanya tersimpan terenkripsi di perangkatmu.

## 3. Siapa yang Bisa Melihat
Kamu melihat data milikmu. Dokter melihat data pasien yang ditanganinya. Admin klinik hanya melihat ringkasan administratif, dan aksesnya dicatat. Tim pengembang hanya memakai data contoh.

## 4. Hakmu
- Lihat dan ubah: menu Profil dan Riwayat
- Salin atau unduh: unduh surat (PDF) dan ekspor data profil
- Hapus: menu Privasi & Data (permanen). Rekam medis tertentu dapat wajib disimpan sesuai aturan; kami akan menjelaskannya di aplikasi

## 5. Perubahan Kebijakan
Jika kami menambah fitur yang mengirim data ke server, kamu akan diminta izin terlebih dulu dan kebijakan ini akan diperbarui.
